# AI Communication Coach

A browser-based communication practice application with a React +
TypeScript frontend and a FastAPI backend.

The application currently provides: - Camera and microphone access for a
practice session. - Browser-based speech recognition and transcript
display (browser support required). - Basic voice measurements,
including microphone signal level and estimated pitch. - Face
visibility, approximate gaze direction, and head-movement indicators. -
A post-session report generated by the backend. - A separate chat
assistant tab with predefined, rule-based communication coaching
responses.

> **Current prototype limitation:** The chat assistant currently uses
> predefined rules and responses. It is not yet connected to a
> generative AI/LLM service and does not provide unrestricted
> general-purpose Q&A. Voice, gaze, and facial measurements are
> approximate indicators; they should not be treated as definitive
> measures of confidence, emotion, attention, or communication ability.

## Start the application

Run the backend and frontend in **two separate VS Code terminals**. Keep
both terminals open while using the application.

### Terminal 1 --- Backend (FastAPI)

1.  Open a terminal in VS Code.

2.  Navigate to the backend directory:

    ``` powershell
    cd C:\Users\Vaishnavi\OneDrive\Desktop\codes\backend
    ```

3.  Activate the Python virtual environment:

    ``` powershell
    .\.venv\Scripts\Activate.ps1
    ```

    When activated, the terminal prompt should begin with `(.venv)`.

4.  Start the FastAPI server:

    ``` powershell
    python -m uvicorn app.main:app --host 127.0.0.1 --port 8000
    ```

5.  Keep this terminal running.

Backend URLs: - API base: `http://127.0.0.1:8000/` - Health check:
`http://127.0.0.1:8000/health` - Interactive API documentation:
`http://127.0.0.1:8000/docs`

### Terminal 2 --- Frontend (React + Vite)

1.  Open a **second** terminal in VS Code. Do not stop the backend
    terminal.

2.  Navigate to the frontend directory:

    ``` powershell
    cd C:\Users\Vaishnavi\OneDrive\Desktop\codes\frontend
    ```

3.  If this is the first run on the machine, or frontend dependencies
    have not yet been installed, run:

    ``` powershell
    npm install
    ```

    This step is normally needed only once, or after dependencies
    change.

4.  Start the frontend development server:

    ``` powershell
    npm run dev
    ```

5.  Keep this terminal running.

Open the application in a browser:

`http://localhost:5173`

## Using the application

### Practice Session

1.  Open the **Practice Session** tab.
2.  Select **Start Camera & Microphone**.
3.  Allow camera and microphone access when the browser asks.
4.  Speak naturally for a short practice session.
5.  Select **Stop Session** to generate the report.
6.  Review the local measurements and backend coaching report.

### Chat Assistant

1.  Select the **Chat Assistant** tab.
2.  Enter a question and select **Send**.
3.  The current prototype recognises a limited set of
    communication-coaching topics, such as:
    -   Interview preparation
    -   Presentations and public speaking
    -   Business meetings
    -   Filler words
    -   Speaking pace
    -   Eye contact and gaze
    -   Speaking confidence

The chat endpoint currently returns predefined responses based on simple
keyword matching.

## Troubleshooting

### PowerShell does not allow virtual-environment activation

If PowerShell blocks the activation script, run this in that terminal:

``` powershell
Set-ExecutionPolicy -Scope Process -ExecutionPolicy RemoteSigned
```

Then activate the environment again:

``` powershell
.\.venv\Scripts\Activate.ps1
```

This changes the execution policy only for the current PowerShell
process.

### Port 8000 is already in use

A backend server may already be running. Stop the existing Uvicorn
server using `Ctrl + C` in the terminal where it was started, then start
it again.

If the original terminal cannot be found, inspect the process using port
8000 before stopping any process:

``` powershell
netstat -ano | findstr :8000
```

Do not terminate an unfamiliar process without confirming that it is the
project's backend.

### Chat displays "I couldn't connect to the chat service"

1.  Confirm that the backend terminal is still running.
2.  Open `http://127.0.0.1:8000/health` and check that it returns a
    healthy status.
3.  Open `http://127.0.0.1:8000/docs` and confirm that the `/chat`
    endpoint is listed.
4.  Refresh the frontend at `http://localhost:5173`.

### Camera or microphone does not start

-   Check browser permissions for camera and microphone.
-   Close other applications that may be using the camera.
-   Use `http://localhost:5173` in a supported browser.
-   Check that the device is connected and selected correctly.
